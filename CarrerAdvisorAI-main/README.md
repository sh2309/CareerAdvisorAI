## Overview

Career Advisor AI is a machine learning project built in Python and Jupyter Notebook that helps users navigate career decisions. By analyzing skills, interests, and market trends, it provides personalized career path recommendations to help users make informed choices about their professional future.

---

## Features

- 🎯 **Personalized Recommendations** — Suggests career paths based on user skills and interests
- 📊 **Data-Driven Insights** — Leverages real-world data to identify in-demand roles
- 🤖 **ML-Powered** — Uses trained models to match profiles with suitable careers
- 📓 **Interactive Notebooks** — Explore and run analyses step-by-step in Jupyter

## Getting Started

### Prerequisites

- Python 3.8+
- Jupyter Notebook or JupyterLab
- pip

### Installation

1. **Clone the repository:**

```sh
git clone https://github.com/Waroo04/CarrerAdvisorAI
cd CarrerAdvisorAI/CarrerAdvisorAI
```

2. **Install dependencies:**

```sh
pip install -r requirements.txt
```

### Usage

Launch Jupyter Notebook:

```sh
jupyter notebook
```

Open the main notebook and run the cells step-by-step to train the model and get career recommendations.
